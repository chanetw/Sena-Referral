System Swimlane · ปัจจุบัน

Flow การทำงานและข้อมูลของ SENA Referral ทั้งระบบ

เอกสารนี้สรุปภาพรวมระบบตอนนี้แบบ swimlane ตั้งแต่การ login, การจัดการ agent / project / customer, lead sync ไป ICON/QAS, ไปจนถึง dashboard, รายงาน และการ retry ของ lead sync logs. จุดสำคัญของ flow ปัจจุบันคือ agent_id ถูกส่งอยู่ใน custom_label ของ payload ที่ยิงไป ICON/QAS และถ้าส่งสำเร็จจะเก็บ iconLeadId ไว้ที่ customer พร้อมบันทึก audit log ทุกครั้ง.

Admin & Agent Workflow

มองเฉพาะการทำงานจริงของคนในระบบ ว่าใครทำอะไร ในจังหวะไหน โดยไม่ลงรายละเอียดเชิงเทคนิค

Admin Agent Action Follow-up Result Decision / Exception
Role / Stage
1. เตรียมพร้อม
2. รับเรื่องลูกค้า
3. ตรวจสอบข้อมูล
4. แจ้งผล / ตัดสินใจ
5. ติดตาม / แก้ไข
6. สรุปผล
Admin ดูแลข้อมูลหลักของระบบ, ตรวจรายการลูกค้า, ตัดสินผล และติดตามภาพรวมงาน
เตรียมข้อมูลให้พร้อม จัดการเอเจนต์, โครงการ และข้อมูลที่ทีมต้องใช้ก่อนเริ่มรับลูกค้า
รับรายการลูกค้าเข้ามา เห็นรายการที่ Agent ส่งเข้าระบบและเปิดดูรายละเอียดของแต่ละราย
← รับต่อจาก Agent
ตรวจสอบความครบถ้วน เช็กว่าข้อมูลซ้ำไหม, ข้อมูลครบไหม, และพร้อมเดินหน้าต่อหรือยัง
ตัดสินผลรายการ อนุมัติ, ไม่ผ่าน, หรือขอข้อมูลเพิ่ม แล้วแจ้งผลกลับให้ Agent รับทราบ
→ แจ้งผลให้ Agent
ติดตามรายการที่มีปัญหา ถ้าข้อมูลไม่ครบหรือมีปัญหา Admin จะตามต่อ, แก้ไข, หรือส่งรายการใหม่
ดูภาพรวมผลงาน สรุปผล, ดูสถานะรายการทั้งหมด และติดตามภาพรวมของทีม
Agent ส่งข้อมูลลูกค้า, ติดตามผลที่ Admin ตรวจสอบ, และช่วยเติมข้อมูลเมื่อมีการส่งกลับมาแก้
เข้าใช้งานและดูข้อมูลพร้อมขาย ดูโครงการและข้อมูลที่ต้องใช้ก่อนเริ่มส่งลูกค้าเข้าระบบ
ส่งข้อมูลลูกค้า กรอกชื่อลูกค้า, เลือกโครงการ, ใส่ข้อมูลติดต่อ และส่งต่อให้ Admin ตรวจสอบ
→ ส่งต่อให้ Admin
รอผลตรวจสอบ ติดตามว่ารายการผ่าน, ซ้ำ, หรือมีจุดที่ต้องเติมข้อมูลเพิ่มหรือไม่
รับผลจาก Admin รู้ว่ารายการผ่านหรือไม่ผ่าน และเข้าใจสถานะของลูกค้าที่ตัวเองส่งมา
ช่วยแก้ไขหรือเติมข้อมูล ถ้ามีข้อมูลตกหล่นหรือ Admin ขอเพิ่ม Agent จะเป็นคนกลับมาอัปเดตข้อมูลให้ครบ
← รับ feedback จาก Admin
ติดตามผลงานของตัวเอง ดูว่าลูกค้าที่ส่งไปอยู่ขั้นตอนไหน และมีอะไรที่ต้องติดตามต่อ

Admin ทำอะไร

Admin เป็นคนดูแลภาพรวม: เตรียมข้อมูล master, รับรายการจาก Agent, ตรวจสอบ, ตัดสินผล และตามต่อเมื่อมีรายการที่ยังไม่เรียบร้อย

Agent ทำอะไร

Agent เป็นคนเริ่มต้นฝั่งหน้างาน: ส่งข้อมูลลูกค้า, รอผลจาก Admin, และกลับมาเติมข้อมูลหรือแก้ไขเมื่อได้รับ feedback

จังหวะสำคัญของงาน

  • จังหวะแรกคือ Agent ส่งลูกค้าเข้ามาให้ Admin เห็นรายการ
  • จังหวะถัดมาคือ Admin ตรวจแล้วแจ้งผลกลับว่า ผ่าน, ไม่ผ่าน, หรือขอข้อมูลเพิ่ม
  • ถ้ามีข้อมูลตกหล่น งานจะวนกลับไปที่ Agent เพื่อแก้และส่งต่อใหม่
section นี้ตั้งใจอธิบายให้เห็นเฉพาะ workflow การทำงานจริงของคนในทีม: Admin กับ Agent ใครรับช่วงไหน และช่วงไหนที่ต้องคุยกันหรือส่งงานกลับไปกลับมา
